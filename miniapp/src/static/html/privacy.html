苏分宝隐私政策

更新日期：2026年8月31日

苏分宝（以下简称"本平台"）非常重视您的个人信息保护。本隐私政策旨在向您说明我们如何收集、使用、存储和保护您的个人信息，以及您享有的相关权利。

一、我们收集的信息

为向您提供服务，我们可能会收集以下信息：

信息类型收集目的具体说明
微信账号信息账号登录昵称、头像、OpenID
手机号码账号绑定与安全验证用于发送验证码、账号找回
订单信息奖励计算与展示电商平台订单号、金额、平台奖励等
设备信息服务优化与安全设备型号、操作系统版本、网络信息
日志信息服务运维访问时间、操作记录、崩溃日志

二、我们如何使用信息

  1. 为您提供商品推荐和奖励计算服务。
  2. 处理您的订单和奖励结算。
  3. 向您发送服务通知（如订单状态变更、奖励到账等）。
  4. 优化产品体验，改善服务质量。
  5. 保障账号安全和平台正常运行。

三、信息共享与披露

我们不会将您的个人信息出售给第三方。以下情况除外：

  1. 经您明确同意或授权。
  2. 为完成订单奖励到账所必需，与电商平台共享必要的订单信息。
  3. 根据法律法规的要求或行政、司法机关的强制性要求。
  4. 为保护本平台及用户的合法权益所合理必需。

四、信息存储与保护

  1. 您的个人信息存储在中国境内的服务器。
  2. 我们采用加密存储、访问控制等安全措施保护您的信息。
  3. 我们会采取合理的技术手段确保数据传输安全。
  4. 如不幸发生信息安全事件，我们将及时告知您并采取补救措施。

五、您的权利

  1. 访问权：您可以在应用内查看您的个人信息、订单和奖励记录。
  2. 更正权：如发现信息有误，您可以联系我们进行更正。
  3. 删除权：您可以申请删除您的个人信息，但可能影响部分功能的正常使用。
  4. 撤回同意：您可以撤回之前的授权同意，但可能影响服务使用。

六、未成年人保护

本平台主要面向成年人服务。如您是未满18周岁的未成年人，请在监护人的陪同下阅读本政策，并在取得监护人同意后使用本服务。

七、政策更新

我们可能会适时修订本隐私政策。政策变更后，我们将在应用内以公告形式通知您。如您继续使用本服务，即表示您同意修订后的政策。

八、联系我们

如您对本隐私政策有任何疑问或建议，请通过平台内客服功能与我们联系。
